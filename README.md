# Harrisons Sales Order Monitoring

## Overview
A responsive React.js web application built for the Harrisons Sabah IT Executive Assessment. It helps a sales team monitor 1,200 sales orders across multiple branches using a mock REST API.

## Features
- Dashboard with global metrics (Total, Open/Pending, Completed, Cancelled, Total Value).
- Order listing with pagination, search, and sorting.
- Filter by Branch/Site and Status.
- Detailed single-order view modal.
- Full responsive design with Loading, Empty, and Error states.

## Tech Stack
- React.js
- Vanilla CSS
- Fetch API

## Run Locally
1. Clone the repo: `git clone [YOUR_GITHUB_LINK]`
2. Install dependencies: `npm install`
3. Start the app: `npm start` (or `npm run dev`)
